# CDD Lab – Collaborative Development and DevOps

## About

This repository contains practical exercises for learning Git, GitHub, version control, branching, collaboration, and DevOps.

## Experiments

1. Experiment 1 – Installation and Configuration of Git
2. Experiment 2 – Git Operations: Clone, Push, Pull and Fetch
3. Experiment 3 – Branching, Merging, Rebasing and Merge Conflicts
4. Experiment 4 – GitHub Issues, Pull Requests and Code Reviews
5. Experiment 5 – Team Collaboration Using GitHub
6. Experiment 6 – Continuous Integration Using GitHub Actions
7. Experiment 7 – Automated Build and Testing

## Tools Used

- Git
- Git Bash
- GitHub
- GitHub Actions
